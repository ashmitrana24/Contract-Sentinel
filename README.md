# Legal Document Fraud & Integrity Analysis Platform

This repository hosts **Module 1: Dataset and Forgery Generator** (`datagen/`), which produces a labeled dataset of clean and tampered contract PDFs for testing downstream fraud-detection modules.

## Repository Layout

```
legal-doc/
├── README.md          (this file)
├── .gitignore
└── datagen/           (the generator package)
    ├── pyproject.toml
    ├── README.md      (detailed usage)
    ├── DECISIONS.md   (design assumptions)
    └── src/datagen/
```

See `datagen/README.md` for full setup and usage instructions.
